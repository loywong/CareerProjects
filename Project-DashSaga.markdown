# 萌神弹斗士 [Project-DashSaga]

**时间：** 2014/12 – 2015/07  
**公司：** 上海东方明珠迪尔希文化传媒 (OPD2C)  
**技术：** [IDE] Unity 5.x；[Language] C#  
**状态：** 商务版

3D Low Ploy风格的大型动作策略类项目，异步对战，类似SuperCell的部落冲突（COC），但是游戏系统设计的丰富程度远甚于COC，其可谓野心不小。实际开发时间大概7个月，并在同行之间取得不错的口碑（由于资方的重大调整和管理上的一些原因，后来团队重组了）。
