# 发条英雄 [Project-UnlimitedTower]

**时间：** 2016/10 – 2017/04  
**公司：** 上海米仁科技  
**技术：** [IDE] Unity 5.x；[Language] C#，Windows BatchFile；[Else] Jenkins  
**框架：** [LowoUN-UI](https://github.com/loywong/LowoUN-UI)  
**状态：** 上线（[https://www.taptap.com/app/47343/](https://www.taptap.com/app/47343/)）

上线产品为《发条英雄》，更像是一个《不休骑士》和《天天打波利》的复合品。作为一个挂机类游戏，系统设计的极其庞大与繁杂，主要工作量在于的UI制作，且UI的动态表现非常丰富（粒子特效，浏览堆栈，列表的展开等）。使用MVVM思想打造的UI框架LowoUN-UI很好的胜任了这一工作，数据，逻辑，表现相分离，使得编写代码更像是处理配置信息。另外通过模板化生成代码。
