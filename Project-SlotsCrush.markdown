# Slots Crush

**时间：** 2019/07  
**公司：** 上海拾玩网络  
**技术：** [IDE] Unity2018.3.6f1，VSCode；[Language] C#，Lua，Python  
**框架：** [LowoUN-Tolua](https://github.com/loywong/LowoUN-Tolua)  
**状态：** 上线（[https://play.google.com/store/apps/details?id=com.slotscrushsa.slots](https://play.google.com/store/apps/details?id=com.slotscrushsa.slots)）

一款Slots游戏，休闲玩法，强社交类型，上线北美和东南亚市场。

使用Unity引擎开发，整合了ToLua框架以便进行业务逻辑脚本的热更新。支持分包按需下载，每一个关卡都可以独立进行资源更新，且更新过程不阻塞玩家正常游玩体验。

和大多数类似产品不同的是，每个关卡的制作非常精良。这个产品并不是一个纯2D游戏，而是采用3D+2D的表现手法，显得更加高级。

这类游戏主打关卡的不同主题和不同玩法，美术工作量满满。

在玩法方面，差异非常之大，截至上线时间为止有20~30个基础类型关卡，每个关卡可以看作是一个新的小游戏。
