# 火源计划 [Project-Mercury]

**时间：** 2013/06 – 2014/04  
**公司：** 上海英佩数码 (EpicGamesChina)  
**技术：** [IDE] UnrealEngine 3，Flash Pro；[Language] UnrealScript，ActionScript3.0，JavaScript  
**框架：** [LowoUI-AS](https://github.com/loywong/LowoUI-AS)，[Batcher-JSFL](https://github.com/loywong/Batcher-JSFL)（批处理脚本）  
**状态：** 上线（[https://0day.ali213.net/html/2016/27257.html](https://0day.ali213.net/html/2016/27257.html)）

大型MMORPG+TPS端游，上线产品为《火源计划》，由腾讯代理发行。

利用模型的动态拼接，真正实现 “百万道具”，“百万地图”。

采用UE3整合Scaleform中间件来作为界面开发方案，以Flash Professional IDE为开发编辑器，Actionscript3.0作为开发语言。并通过JSFL（JavaScript语法）批处理脚本优化工作流效率（针对资源导入和发布）。

UI设计采用科幻感十足的[FUI风格](https://zhuanlan.zhihu.com/p/94205859)，开发框架则采用我搭建的基于ActionScript 3.0的框架[LowoUI-AS](https://github.com/loywong/LowoUI-AS)。最终呈现出表现丰富的强交互式体验（早期版本的美术界面和交互动画都由我设计与制作，后续美术同事也延续了我设定的风格）。
